## 🚀 How to Run & Preview

### Option 1: Direct Double Click
Simply double-click `index.html` to open it in your browser (Chrome, Edge, Safari, Firefox).

### Option 2: Local HTTP Server (Recommended for audio)
Run in PowerShell / Terminal:
```bash
# Python
python -m http.server 8000

# or Node.js (if npx installed)
npx serve
```
Then open `http://localhost:8000` in your browser.

## 🎵 How to Add Your Music (*Pottala Muttaye*)

1. Place your audio file in `assets/audio/pottala_muttaye.mp3`.
2. The website will automatically play it when Sowmya clicks **"♫ Play our story with sound"**!
3. If no MP3 is found, the built-in cinematic synthesizer will automatically generate dynamic acoustic chords so there is always music.
